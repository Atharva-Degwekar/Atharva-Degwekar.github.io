# Atharva Degwekar: Product Portfolio

Live site: https://atharva-degwekar.github.io

Static, dependency-free portfolio (HTML, CSS and vanilla JS). Fonts come from Google Fonts.

| Path | What it is |
|---|---|
| `index.html` | The portfolio |
| `assets/` | Résumé PDF, Kavach walkthrough video and screenshots, n8n workflow image |
| `demos/kavach.html` | Kavach POC (needs internet for maps and charts) |
| `demos/codex-to-claude-runbook.html` | Codex → Claude Code seminar runbook |

## Add your video résumé
Export your recording as MP4 (H.264, 1080p or 720p, under 100 MB), name it `video-resume.mp4`, put it in `assets/`, and push. The placeholder on the page swaps to the player on its own.
If the file is over 100 MB, upload it to YouTube or Drive (unlisted) instead and change the "Video résumé" button link.
